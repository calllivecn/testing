## apt install vainfo

- vsinfo 查看： 输出中的 VAEntrypointVLD 表示支持视频解码（Video Layer Decoding）。如果看到了 H264、HEVC、VP9 等，就说明你的 CPU 支持这些格式的硬件解码。

- VAEntrypointEncSliceLP 和 VAEntrypointEncPicture 代表硬件编码，而不是解码。例如：

- VAProfileH264Main : VAEntrypointEncSliceLP 表示支持 H.264 Main 配置文件的硬件编码。

- VAProfileJPEGBaseline : VAEntrypointEncPicture 表示支持 JPEG 基线配置文件的硬件编码。
